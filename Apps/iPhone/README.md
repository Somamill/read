# read. for iPhone

A local-first React Native reader for **Expo Go SDK 58**. Import EPUBs, read saved articles, follow feeds, highlight passages and connect your own reading services.

```sh
npm ci
npx expo start --go
```

Scan the QR with an iPhone running Expo Go 58.0.5 / SDK 58. No Apple Developer membership required. The preview server must remain running.

See the [mobile setup guide, feature matrix and publishing instructions](../../Documentation/IPHONE.md). This is an initial mobile preview; macOS-only integrations are not available in Expo Go.
