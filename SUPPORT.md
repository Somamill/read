# read. support

Email [k4jenx@gmail.com](mailto:k4jenx@gmail.com) or open a [GitHub issue](https://github.com/Somamill/read/issues). Include your app version, platform, what you tried and any visible error. Do not post passwords, API tokens, private library addresses or copyrighted book files.

The Store edition reads imported files locally; optional library, Readwise and Hardcover connections need their own reachable services and credentials. No connection is required to import a local EPUB. The full community Mac edition includes additional external integrations.

If a file fails to import, confirm it is unprotected and supported, then try importing another file. Keep original files and export backups before deleting the app. See the [privacy policy](PRIVACY.md) for local storage and optional service behavior.
